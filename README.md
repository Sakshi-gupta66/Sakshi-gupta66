**B.Tech Electrical Engineering student building LLM-powered applications — RAG, retrieval pipelines, and agentic workflows.**

I build AI features that sit inside real products: chat with your documents, assistive communication without expensive hardware, and agents that audit and explain their own decisions. Currently focused on GenAI/LLM applications in Python.

## 🔭 Featured Projects

### 📄 [StudyLens](https://github.com/Sakshi-gupta66/StudyLens)
RAG app that chats with PDFs and answers with page-cited sources.
- PDF chunking with page metadata, MiniLM embeddings, vector search, cross-encoder reranking
- FastAPI backend, OpenRouter LLM for grounded answers
- **Stack:** Python, FastAPI, Hugging Face, PyMuPDF, NumPy

### 🎙️ [SilentVoice](https://github.com/Sakshi-gupta66/SilentVoice)
Headset-free assistive communication: mouth silently into your webcam, hear it spoken aloud.
- Browser camera capture, Gemini lip-reading, text-to-speech playback
- Built as a semester major project — assistive tech with zero hardware cost
- **Stack:** Python, Flask, JavaScript, Gemini API, gTTS

### ⚙️ [Distributed-Job-Processing-System](https://github.com/Sakshi-gupta66/Distributed-Job-Processing-System)
A distributed job queue with reliable, at-least-once processing.
- FastAPI + PostgreSQL + Redis Streams consumer groups, idempotency keys, exponential backoff, dead-letter queue, recovery
- Docker Compose for one-command local deployment
- **Stack:** Python, FastAPI, PostgreSQL, Redis, Docker

### 🪐 [B13-ExoHabitAI](https://github.com/Sakshi-gupta66/B13-ExoHabitAI)
Infosys Springboard internship project (Feb–Apr 2026): predicting exoplanet habitability from astrophysical data.
- My work: classification models, exploratory data analysis, handling missing values, feature selection
- **Stack:** Python, scikit-learn, Pandas, NumPy, Matplotlib, Flask
